# Introduction

近年来，模仿学习在机器人操作策略的学习中取得了显著进展。然而，现有的大多数方法仍依赖于机器人数据进行训练，这些数据通常通过遥操作或仿真采集。尽管有效，但这类方法在可扩展性方面存在显著挑战：遥操作数据采集成本高昂，效率低下，而仿真环境则难以准确建模诸如流体、软体结构等复杂物理过程。

为了解决这些问题，越来越多的研究开始探索使用人类演示视频作为替代监督源，推动“人类到机器人”的策略迁移。一些方法依赖于Paired Human-Robot Videos（Human2Robot, Vid2Robot），这类方法通常借助VR设备去实现人和机器人动作的高度同步，收集起来非常的困难，限制了其大规模地应用。为此，人们开始研究如何使用unpaired的数据实现人到机器人的迁移。其大致可以分为两类方法，一类是将人类和机器人数据联合训练一个模型（EgoMimic，UP-VLA），另一类是探索人类和机器人的统一表征，包括一些隐式的表征（IGOR，LAPA，XSkill，MimicPlay, RHyME）或是显式的表征（Im2Flow2Act）。第一类方法通常是端到端的；而第二类方法则是两阶段的，首先训练一个模型输出统一表征，再训练一个策略模型基于表征输出动作。但这些方法依然需要机器人本体的数据进行训练，限制了其在不同机器人上的泛化性。人们开始探索一些robot data free的方法，这些方法不需要任何的机器人本体数据，使其具有很好的跨具身的泛化性。其中很重要的一类是One-Shot Imitation Learning（OSIL），这类方法从人类视频中提取轨迹和其他的一些关键信息（比如一些关联物体的6D pose，人手和物体的接触点，抓握状态等），然后通过坐标变换（OKAMI, OSIL: APEP）或者基于关键信息进行轨迹优化（FUNCTO，ScrewMimic）的方式，得到机器人的操作。但这一类方法通常是开环控制，无法处理复杂的任务。

闭环控制的robot data free方法，需要依赖于预定义的中间状态，比如2D/3D的光流（ToolFlowNet, Track2Act，General Flow），物体6DoF位姿（SPOT，FreePose，Tool-as-Interface），手部/手腕轨迹（ZeroMimic，WHIRL）。由于人手和机器人末端执行器大小存在差异，基于手腕轨迹的方法无法实现高精度的操作，容易失败，其中一些方法在此基础上通过机器人与真实环境交互（WHIRL）进行微调，实现高精度地操作。2D Flow由于缺乏深度信息，在执行时需要通过额外的处理转化成机器人实际可操作的动作，Track2Act利用初始帧的RGBD相机获得深度信息，并在后续帧使用PnP得到3D Flow，因此引入了较大的估计误差，难以执行高精度的任务。因此，想要做到robot data free的高精度操作，就只有依赖物体的6DoF Pose或者精确的3D Flow作为中间表示。3D Flow在表示非刚体类物体时具有显著的优势，但对于刚体类物体来说，其通常需要通过SVD得到物体的6DoF Pose，相比于直接使用6DoF Pose表示多次一举，而且精度较低。考虑到大多数工具都是刚体，使用6DoF表示已经可以涵盖大多数场景了，因此我们选择使用6DoF的中间表示。

为此，我们提出了**ODPC**：一种**从第三人称RGBD人类视频中学习端到端、闭环、高精度的视觉动作策略**，用于工具使用操作的新方法，无需任何机器人演示数据。与上述两阶段的方法不同，ODPC从RGBD视频中直接预测物体的未来6DoF轨迹，保留了完整的视觉语义线索，可以用于学习复杂的世界模型。此外，与直接预测物体6-DoF姿态的方法不同，DeltaCtrl 学习预测工具在相机坐标系下的相对位姿变化（delta transformation，记作 ΔT），并通过闭环控制策略将预测结果实时转化为末端执行器的运动命令，避免了物体坐标系定义导致的歧义，并且可以泛化到不同的相机设备和物体上。

我们的方法首先使用RGBD视频对人类示范中的工具轨迹进行6-DoF姿态估计，随后使用扩散策略网络（Diffusion Policy）进行训练，学习从RGBD图像预测未来若干步的 $\Delta T$ 序列。在部署阶段，机器人首先通过现有的基于affordance的抓取策略完成工具抓取，然后利用训练好的模型实时预测工具运动，并通过一个简单但稳定的运动变换公式将其转化为控制指令，驱动机械臂执行。

我们在一个**高精度、高动态反馈需求的现实任务**中对该方法进行了验证。具体来说，我们设计了一个使用**矿泉水瓶从机械按钮式饮水机接水**的任务。该任务要求机器人一方面精确控制水瓶瓶口对准出水口，另一方面用水瓶按压出水按钮以启动水流。由于瓶口狭小，对准误差极易导致漏水或无法接水，此外机器人还需要**根据水流情况实时调整策略**（如无水流则加压、漏水则对准、装满则停止）。在该任务中，ODPC 展现出良好的稳定性和精度，证明了从人类RGBD演示中学习精细操作策略的可行性和通用性。

本文的主要贡献点包括：
1. **提出了ODPC的框架**：首次实现了**仅使用人类数据**，学习**高精度**、依赖**闭环视觉反馈**的**工具使用**策略。
2. $\Delta T$预测：我们提出预测相机坐标系下物体变化的矩阵，绕过了工具的物体坐标系定义歧义导致的学习困难，不需要标定物体到末端执行器的位姿，不需要显式估计物体6DoF位姿，不需要物体的mesh，具有良好物体、视角、跨具身（相机设备）泛化性。
3. 误差分析：在仿真环境中分析了不同误差对最终成功率的影响，包括相机到机械臂基座的标定误差、末端执行器位姿估计误差、控制执行误差，以及视觉运动策略预测 $\Delta T$ 所带来的不确定性
4. 真机实验和泛化性分析：在真实场景下进行了4个任务的实验，包括上面所说的接水实验，以及拧螺丝，倒水，开门，证明了该方法能够广泛应用于不同的任务场景，只需要被操作物体是刚体。在接水实验中进行了详细的泛化性分析，结果表明该方法能够泛化到未见过的新物体和新的视角上，并探索了相应的scaling law，表明随着人类的数据增加，机器人操作的成功率呈现指数规律。
